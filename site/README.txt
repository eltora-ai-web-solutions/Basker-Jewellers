BASKAR JEWELLERS WEBSITE
========================
Website : index.html
Admin   : admin.html

HOW TO RUN ON YOUR COMPUTER (Windows)
1. Extract the zip. Keep the folder anywhere (e.g. D:\BaskarWebsite).
2. Double-click  start.bat  (needs Python). It opens the website and the admin.
   Or in a terminal inside this folder:  python server.py
3. Log in to the admin, make changes, click "Save Changes".
   Files are saved into this folder automatically - no folder box.
4. Refresh the website page to see the changes.

Keep the server window open while you work. Close it to stop.
Admin login is set inside admin.html. Change the password before going live.
